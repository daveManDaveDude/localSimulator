## Interaction observations

The Playwright test used the actual rendered app and browser pointer lock. It did not mock pointer lock or change camera values from test code. Its normal-load checks recorded no console errors, uncaught page errors, failed requests, or HTTP error responses.

- Spawn was `(0, 8.5, 15.2)` metres. Holding W moved along the camera look direction to approximately `(0, 6.89, 11.95)`; A and D changed X in opposite directions.
- Space raised the camera, Ctrl lowered it, and Shift more than doubled reported flight speed while producing greater travel.
- Mouse movement changed bearing from 0.0° to 40.6° and pitch from −26.4° to −24.7°. The Reset button and R key returned position, bearing, and pitch to spawn.
- Resizing updated both CSS and backing canvas dimensions at the capped pixel ratio.
- Pressing Escape while pointer-locked released the browser pointer lock through the controller's Escape-key path. The test then confirmed movement stopped while W remained held, and the UI exposed Resume flying.

The key behavior was verified through Chromium's real pointer-lock API and Playwright's keyboard input. A headed Playwright run was also attempted but could not start the managed browser process: `browserType.launch: spawn UNKNOWN` for the installed Playwright Chromium executable. Therefore there is no headed or physical-keyboard Escape observation in this record.

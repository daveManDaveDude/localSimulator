# TVW-013: Ground-following walk mode

**Status:** Implementation submitted for independent review. TVW-014 remains unauthorized.

## Delivered

- Added fly, entering-walk and walk controller states. Fly remains full look-direction movement; walk follows camera yaw and holds the camera at the active terrain sample plus 1.7 m.
- Set both modes to 15 m/s normal movement and 41.25 m/s with Shift (2.75×). Combined directions are normalized. Walking ignores vertical keys; fly retains Space/Ctrl vertical movement.
- Added smooth fly-to-walk vertical acquisition at up to 20 m/s, rejection below terrain, cancellation, mode-preserving reset behavior, and feedback when a terrain sample is unavailable.
- Walk updates use the current world sampler and clamp horizontal coordinates to the active bounds before sampling. Frame time is capped at 0.25 seconds per update and split into steps no larger than 0.05 seconds.
- Added an accessible fly/walk button, the locked `F` shortcut, and HUD/help for navigation mode, configured speed, sampled ground and eye clearance. Input is cleared on unlock, blur, visibility changes, reset and disposal.
- Updated README controls and M6 status. Synthetic remains the default, and the M0, terrain-only and combined local routes remain available.

## Fix round 1

- Navigation now suspends every controller update while the window is blurred or the document is hidden. The controller clears held keys on both transitions, requires both focus and visibility before resuming, and discards the first resumed animation update to prevent paused time from becoming camera travel.
- Walk heading now comes from PointerLockControls' YXZ camera yaw instead of the horizontal projection of the look vector. This keeps forward movement stable as pitch approaches or reaches either vertical direction.
- Added lifecycle unit tests for blur, hidden state, combined focus/visibility recovery and first-frame discard. Added camera-to-walk movement tests at near-vertical and exact vertical pitch. The Chromium navigation regression pauses an active acquisition on blur, verifies pointer lock remains held and position stays fixed, then confirms focus resumes the acquisition.

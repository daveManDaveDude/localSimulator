# TVW-011: Optional OSM road layer

**Status:** Fix round 2 submitted for independent review. TVW-011 does not complete the combined M5 exit gate; TVW-012 remains separate and unauthorized.

## Delivered

- Added an offline road extraction, exact AOI clipping, visual-width policy, terrain-triangle subdivision, QA preview, package validation and atomic publication workflow. The browser loads the local road package only when `roads=1` is selected for `world=torquay-poc-001`.
- Added a typed road package contract and indexed terrain-draped ribbon renderer. The existing synthetic default, `/?world=m0`, synthetic heightfield, real terrain-only and building routes remain available. Synthetic startup does not request road assets.
- Added independent visibility, wireframe, landmark/debug selection, loading/error/retry feedback, OSM and Geofabrik attribution, and the pending coverage/completeness notice. Widths are visual estimates. Missing vertical tags are treated only as a ground-level rendering assumption; bridge, tunnel, covered, nonzero-layer and ambiguous vertical cases are excluded.
- Road surfaces are constrained to the existing terrain triangles and offset by 0.05 m. The exporter culls only triangles whose XZ coordinates collapse after Float32 conversion, bounded by a 1e-6 m² omitted-area limit. The actual package records two culled triangles with combined area 4.35e-10 m².

## Fix round 1 submitted for independent review

The review fixes harden the browser contract and QA as follows: the ground-draped policy now rejects retained bridge/tunnel/covered tags and unsupported layer values, and the inverse coordinate operation must match the complete pinned pipeline definition. Road triangle validation now catches duplicate triangles by coordinates even when they use copied vertices, rejects overlapping triangle interiors, validates malformed nested manifest/QA/count and vertex data with schema issues, and reconciles displayed triangle area with QA totals. The QA preview north arrow points up-screen for north (negative Z).

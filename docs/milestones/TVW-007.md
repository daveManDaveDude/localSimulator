# TVW-007 — EA DTM source inspection

**Implementation status:** initial implementation complete; pending independent review.

**Scope:** EA LIDAR Composite DTM 1 m (2022 composite) over the reviewed 1,000 m × 1,000 m AOI. This issue does not inspect OSM/OS buildings or roads, create a browser real-data world, or export a heightfield for the viewer.

## Results

The two public Environment Agency portal tiles `SX96nw` and `SX96sw` were downloaded on 2026-10-17. Exact portal URLs, archives, sizes, hashes, member lists, GeoTIFF metadata, XML sidecar digests, and publisher terms are in [data/source-manifest.json](../../data/source-manifest.json). The archives and extracted files live under ignored `data/raw/ea_dtm/` and are not committed.

The exact AOI is EPSG:27700 bounds `[290608.9018176432, 64853.48350844931, 291608.9018176432, 65853.48350844931]` in west, south, east, north order. Analysis uses a 1 m grid aligned to those bounds and samples each grid cell center from the containing source pixel. No interpolation, extrapolation, reprojection or NoData fill is applied.

The [generated coverage report](artifacts/TVW-007-coverage.json) measures:

- 1,000,000 of 1,000,000 analysis cells valid (100%).
- 0 uncovered cells, 0 masked/NoData cells and 0 nonfinite cells.
- 0 missing cells / 0 m² missing analysis-grid area; the EA DTM result passes the 1% missing threshold.
- Minimum 29.528999 m, maximum 98.171005 m; the configured center samples 47.619999 m from `SX96nw_DTM_1m.tif`.
- North tile contribution 853,000 cells and south tile contribution 147,000 cells; no overlap cells.

The source tile XML says metres relative to Ordnance Survey Newlyn using OSTN 15 and OSGM 15. The product-wide catalogue survey dates are 2000-06-06 through 2022-04-02; each tile XML describes its composite period as 2003-02-14 through 2022-05-05. These statements do not establish a single per-pixel survey date. The XML also reports ±15 cm RMSE as a product accuracy claim, not a local measurement. The XML has a conflicting `idCredit` copyright year of 2020, while its explicit reuse instruction requires the 2022 Environment Agency attribution; the latter is used.

The [north-up preview](screenshots/TVW-007-ea-dtm-preview.png) was generated from the same AOI analysis grid. It shows measured relief, exact AOI bounds, EPSG:27700 metre axes, a 250 m scale bar with end ticks, the configured center marker and sample, elevation colorbar, missing-cell styling, and required Environment Agency attribution. The PNG was opened and visually inspected after generation; the scale bar and label are visible in the lower-right of the map axes.

## Reproduce locally

From the repository root, restore the ignored source files using [docs/data-sources.md](../data-sources.md), then run:

```powershell
Push-Location pipeline
.\.venv\Scripts\python.exe -m torquay_pipeline.cli inspect-sources
.\.venv\Scripts\python.exe -m torquay_pipeline.cli preview-terrain
.\.venv\Scripts\python.exe -m pytest tests
.\.venv\Scripts\ruff.exe check torquay_pipeline tests
.\.venv\Scripts\ruff.exe format --check torquay_pipeline tests
Pop-Location
```

The source manifest verifier checks archive byte lengths and SHA-256, ZIP members and CRC, XML sidecar digests, GeoTIFF structural metadata, and measured full-tile statistics before coverage runs. Raw source data remains outside Git.
